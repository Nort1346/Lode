# i18n

## Overview

StreamHub supports Polish (default) and English via `@nuxtjs/i18n` v10.

## Configuration

### nuxt.config.ts
```ts
i18n: {
  locales: [
    { code: 'pl', name: 'Polski', file: 'pl.json' },
    { code: 'en', name: 'English', file: 'en.json' }
  ],
  defaultLocale: 'pl',
  strategy: 'no_prefix',
  detectBrowserLanguage: {
    useCookie: true,
    cookieKey: 'i18n_lang',
    redirectOn: 'root'
  }
}
```

### Key Settings
- **Strategy**: `no_prefix` — no URL prefix for locales
- **Default**: Polish (`pl`)
- **Detection**: Cookie-based (`i18n_lang`)
- **Redirect**: Only on root path

## Locale Files

Located in `i18n/locales/`:
- `pl.json` — Polish translations (primary)
- `en.json` — English translations

## Usage

### In Vue Components
```vue
<script setup>
const { t, locale, locales, setLocale } = useI18n()
</script>

<template>
  <p>{{ t('nav.dashboard') }}</p>
  <USelect
    :model-value="locale"
    :items="localeOptions"
    @update:model-value="setLocale($event as 'pl' | 'en')"
  />
</template>
```

### In Server Code
```ts
import { useI18nServer } from '#server/utils/i18n-server'

const { t } = useI18nServer(locale)
const message = t('discord.downloadComplete', { title, size })
```

## Changing Locale

When changing locale, use `setLocale()` from `useI18n()`:

```ts
// ✅ Correct
setLocale($event)

// ❌ Wrong — doesn't trigger reactivity
locale.value = $event
```

## TMDB Locale

TMDB API calls use the current i18n locale for localized results:
- `pl` → Polish titles, overviews, names
- `en` → English titles, overviews, names

The locale is passed as a query parameter to all browse API endpoints.

## Discord Locale

Discord notifications have a separate locale setting:
- Configurable in Admin → Settings → Discord Locale
- Independent of UI locale
- Options: `pl` or `en`

## Rules

1. **Polish translations MUST be in Polish** — no English fallbacks
2. **No Google Translate** — all translations are manually written
3. **All UI strings MUST use `t('key')`** — no hardcoded strings
4. **Server-side i18n** uses `useI18nServer()` for Discord/webhook messages
